# Retail Sales Dashboard - Portfolio

Dashboard penjualan retail interaktif berbasis Flask + Chart.js.

> ⚠️ **DISCLAIMER:** Semua data di repo ini adalah **DATA DUMMY** untuk keperluan portfolio. Bukan data perusahaan, margin, budget, atau customer asli.

## Fitur
- Dashboard Utama: KPI, tren penjualan bulanan, breakdown kategori
- Customer Root Cause: Analisa alasan customer tidak jadi beli (anonim)
- Forecast: Simulasi 3 skenario Pessimistic / Base / Optimistic

## Cara Jalanin
```bash
pip install flask
python server.py
